# TWICE ARCHIVE

**TWICE ARCHIVE** 是一個以韓國女子團體 TWICE 為主題的非官方粉絲資料整理網站，使用繁體中文呈現，透過簡潔的雜誌風格版面，整理團體資訊、成員介紹與音樂作品。

## 專案介紹

本網站希望讓瀏覽者能夠透過不同分類，快速認識 TWICE 的團體背景、九位成員，以及部分代表性音樂作品。

網站採用簡約的編輯雜誌風格，並以 TWICE 的代表色作為主要視覺配色。

## 網站功能

目前網站包含四個主要頁面：

1. **首頁（Home）**：網站主視覺、簡介與三大內容分類入口。
2. **團體介紹（About TWICE）**：團體背景、出道資訊與基本資料。
3. **成員介紹（Members）**：九位成員的照片、中英文姓名、韓文姓名與生日。
4. **音樂作品（Discography）**：依照發行日期排列 TWICE 的韓文專輯，並標示專輯名稱、發行日期及專輯類型，本頁不收錄日文專輯及成員個人作品。

## 使用技術

- HTML：建立網站頁面與內容結構。
- CSS：設計網站版面、配色與響應式樣式。
- JavaScript：處理頁尾年份更新與目前頁面的導覽列標示。

## 視覺設計

網站以 TWICE 的代表色作為主要配色：

- 杏色：`#FCC89B`
- 螢光洋紅：`#FF5FA2`

整體採用簡約、清晰的雜誌編排風格，並保留適當留白。

## 如何瀏覽

下載或複製本專案後，使用瀏覽器開啟根目錄中的 `index.html`，即可瀏覽網站。

## AI 開發規範

本專案使用 `AGENTS.md` 作為 AI 開發規範，記錄網站的設計方向、配色、檔案結構與程式撰寫原則。

未來若要新增頁面或修改內容，可以先閱讀 `AGENTS.md`，讓 AI 依照既有規範延續網站的設計與架構。
